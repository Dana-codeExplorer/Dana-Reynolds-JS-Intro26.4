Instructions on Cat API page:
There are two parts:
1. The user can push the get breeds button to see all the cat breeds.  The cat breeds include the cat's breed, the cats origin and an image.
   When the user is finished they can push the clear breeds button to clear the screen.
2. The user could also search for a specific breed. Type the breed you want to see in the input field then click the search button to see three images of cats belonging to that breed.
